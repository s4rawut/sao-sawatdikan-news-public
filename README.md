# เว็บไซต์สวัสดิการ สำนักงานการตรวจเงินแผ่นดิน

เว็บไซต์ข่าวสารและสิทธิประโยชน์สวัสดิการ พร้อมระบบร้านค้าสวัสดิการออนไลน์ สำหรับบุคลากร สตง.

**ติดตั้งบนเซิร์ฟเวอร์ภายใน: อ่าน [docs/self-hosting.md](docs/self-hosting.md)**

## ระบบมีอะไรบ้าง

| ส่วน | รายละเอียด |
|---|---|
| เว็บไซต์ | หน้าแรก (แบนเนอร์/ป๊อปอัปเปิดปิดได้), ข่าวประชาสัมพันธ์, สิทธิประโยชน์, ภารกิจและคณะกรรมการ, ระเบียบและหลักเกณฑ์, รายงานฐานะการเงิน, ชมรม |
| หลังบ้านเว็บไซต์ | `/_emdash/admin` — แก้เนื้อหา รูป ไฟล์แนบ เมนู แบนเนอร์ ป๊อปอัป (EmDash CMS, เข้าด้วย passkey) |
| ร้านค้าสวัสดิการ | `/shop` รายการสินค้า, `/member` สมาชิก ตะกร้า สั่งซื้อ แนบสลิป ติดตามสถานะ รับสินค้าส่วนกลาง/ส่งไปรษณีย์ส่วนภูมิภาค |
| หลังบ้านร้านค้า | `/shop-admin` — คำสั่งซื้อ ตรวจสลิป สต็อก สินค้า สมาชิก ผู้ดูแลร้าน (สิทธิ์แยกได้) อัปโหลดรายชื่อบุคลากร ตั้งค่าร้าน รายงานยอดขาย |
| สมัครสมาชิก | ตรวจสิทธิ์ด้วยอีเมลสำนักงาน + วันเดือนปีเกิด กับรายชื่อบุคลากรที่ผู้ดูแลอัปโหลด (เก็บวันเกิดเป็นค่า hash ไม่เก็บวันเกิดจริง) |

## เทคโนโลยี

- [Astro 7](https://astro.build) + [EmDash CMS](https://docs.emdashcms.com) (server-rendered)
- รันบน **Node.js** ใช้ฐานข้อมูล **SQLite** ไฟล์เดียว และเก็บไฟล์อัปโหลดในโฟลเดอร์บนดิสก์ — ไม่ต้องติดตั้ง database server
- ติดตั้งได้บนเครื่อง Linux/VM, Windows Server หรือ Docker/แพลตฟอร์ม container ของ cloud ใดก็ได้ (ดูคู่มือ)

## โครงสร้างโฟลเดอร์

```
src/
  pages/            หน้าเว็บ (Astro) — /, /shop, /member, /shop-admin, /pages/[slug], /posts …
  components/       ส่วนประกอบหน้า (แบนเนอร์ ป๊อปอัป การ์ดสินค้า ฯลฯ)
  layouts/Base.astro  โครงหน้าเว็บ เมนู ส่วนท้าย
  shop/api.js       API ร้านค้าทั้งหมด (สมาชิก คำสั่งซื้อ สต็อก หลังบ้านร้าน)
  platform/         การเชื่อมฐานข้อมูล SQLite และโฟลเดอร์ไฟล์สำหรับโค้ดร้านค้า
  site-gate.ts      รหัสเข้าเว็บช่วงทดสอบ (เปิดเมื่อตั้ง SITE_GATE_USER/PASS)
public/
  shop/             หน้าเว็บสมาชิกและหลังบ้านร้านค้า (JavaScript ฝั่งเบราว์เซอร์)
  vendor/           ไลบรารีที่ใช้ในหน้าเว็บ (เก็บในเว็บเอง ไม่ต้องโหลดจากอินเทอร์เน็ต)
seed/seed.json      โครงสร้างข้อมูลของ EmDash (collection, field) และเนื้อหาเริ่มต้น
scripts/            build-node, backup, admin-login-link, export-static
deploy/             ตัวอย่าง systemd service และ nginx
docs/               คู่มือติดตั้ง (self-hosting.md)
Dockerfile, docker-compose.yml   ทางเลือกติดตั้งด้วย Docker
```

## คำสั่ง

```bash
npm ci                 # ติดตั้งแพ็กเกจ
npm run build          # build (อ่านค่าจาก .env — ดู .env.example)
npm start              # รันเซิร์ฟเวอร์ (พอร์ต 4321)
npm run backup         # สำรองฐานข้อมูล + ไฟล์ (ทำได้ขณะเว็บเปิด)
npm run admin-link -- <email>   # ลิงก์เข้าหลังบ้านเว็บไซต์ครั้งเดียว (ใช้ตอนย้ายโดเมน)
npm run dev            # โหมดพัฒนา
```

## ข้อมูลที่ไม่อยู่ใน Git

ฐานข้อมูล (`data/emdash.db`), ไฟล์อัปโหลด (`data/uploads/`), ค่าลับ (`.env`) และไฟล์สำรอง **ไม่อยู่ใน repository นี้**
เพราะมีข้อมูลส่วนบุคคล — ผู้พัฒนาส่งให้แยกในวันย้ายระบบ (ดูข้อ 4 ใน docs/self-hosting.md)
